## Introduction
This application is part of Oulu University of Applied Sciences Web development course. Goal of this project is to develop a web application consisting of frontend built using React, Node.js backend and a PostgreSQL database.  
  
Functionality of the app includes several features including the following:    
  

| ID | Feature                        | Points    |
|----|--------------------------------|-----------|
| 1  | Responsiveness                 | 2 p.      |
| 2  | Registration                   | 1 p.      |
| 3  | Login                          | 1 p.      |
| 4  | Account deletion               | 1 p.      |
| 5  | Search                         | 2 p.      |
| 6  | Now in theaters                | 1 p.      |
| 7  | Group page                     | 2 p.      |
| 8  | Adding a member                | 1 p.      |
| 9  | Removing a member              | 1 p.      |
| 10 | Group page customization       | 2 p.      |
| 11 | Movie review                   | 2 p.      |
| 12 | Browsing reviews               | 1 p.      |
| 13 | Favorites list                 | 1 p.      |
| 14 | Sharing the favorites list     | 1 p.      |
| 15 | Free-choice feature            | 1 p.      |
|    | **Total**                      | **20 p.** |
